# M.R AI — نمونه موبایلی ۰٫۳

## این نمونه چه کاری انجام می‌دهد؟
- بدون API و بدون اتصال به هوش مصنوعی خارجی، نوع درخواست را با قواعد داخلی تشخیص می‌دهد.
- برای تصویر، ویدئو، موسیقی، طراحی شخصیت و برنامه‌ریزی عمومی مراحل و پرامپت پیشنهادی می‌سازد.
- شخصیت‌ها و پروژه‌ها را در حافظه محلی مرورگر ذخیره می‌کند.
- خروجی پشتیبان JSON می‌دهد.
- رابط فارسی/انگلیسی و حالت راست‌به‌چپ/چپ‌به‌راست دارد.
- پس از نصب به‌صورت PWA، فایل‌های رابط را برای استفاده آفلاین کش می‌کند.

## نصب روی اندروید
برای نصب واقعی به‌صورت PWA، فایل‌ها باید روی یک نشانی HTTPS میزبانی شوند:
1. پوشه را روی یک سرویس میزبانی ایستا مانند GitHub Pages یا Cloudflare Pages منتشر کنید.
2. نشانی HTTPS را با Chrome گوشی باز کنید.
3. از منوی Chrome گزینه Install app یا Add to Home screen را بزنید.
4. برنامه از صفحه اصلی باز می‌شود. پس از بارگذاری نخست، رابط برنامه آفلاین هم باز می‌شود.

بازکردن مستقیم index.html از فایل‌منیجر برای آزمایش ممکن است، اما نصب PWA و سرویس آفلاین در آن حالت تضمین نمی‌شود.

## محدودیت‌های صادقانه
- این «مغز» فعلاً موتور قانون‌محور و تصمیم‌گیری محدود است؛ مدل زبانی آموزش‌دیده یا استدلال عمومی در سطح انسان نیست.
- هیچ تصویر، ویدئو یا موسیقی واقعی تولید نمی‌کند؛ فقط برنامه و پرامپت می‌سازد.
- حافظه روی همان مرورگر/دستگاه است؛ پاک‌کردن داده‌های مرورگر می‌تواند آن را حذف کند. از JSON پشتیبان بگیرید.
- داده‌ها همگام‌سازی ابری یا رمزگذاری اختصاصی ندارند؛ اطلاعات حساس وارد نکنید.
- برای تبدیل آن به اپلیکیشن Android APK باید مرحله بعدی بسته‌بندی و امضای اندروید انجام شود.

## هدف آزمایش
لطفاً چند درخواست متفاوت را امتحان کنید و بررسی کنید:
1. آیا نوع پروژه را درست تشخیص می‌دهد؟
2. آیا مراحل پیشنهادی مفید و منطقی هستند؟
3. آیا پرامپت خروجی به خواسته شما نزدیک است؟
4. آیا شخصیت و پروژه پس از بستن و بازکردن برنامه باقی می‌مانند؟
5. چه قابلیتی کم است یا چه تصمیمی اشتباه است؟

این بازخوردها مبنای نسخه ۰٫۴ خواهند بود.


## تغییرات نسخه ۰٫۴
- لوگوی تأییدشده و بدون تصویر انسان در سربرگ و آیکون نصب.
- انتخاب شخصیت ذخیره‌شده برای هر درخواست و افزودن ویژگی‌های ثابت آن به پرامپت.
